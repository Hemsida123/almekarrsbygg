Öppna index.html i en webbläsare för att visa förslaget.

Det här är ett fristående HTML-dokument med inbäddad CSS och JavaScript. Bilderna hämtas från Almekärrs Byggnads AB:s publika webbplats, så internetanslutning behövs för att visa fotografierna. Typsnitten hämtas från Google Fonts med systemtypsnitt som reserv.

Företagsbeskrivning, tjänster, kontaktuppgifter och exempel på byggnadsvårdsuppdrag har sammanställts från almekarrsbygg.se. Jag hittade inga omdömen som gick att verifiera och har därför inte lagt in kundcitat eller betyg.

Sidan är ett lokalt webbplatsförslag och har inte publicerats.
